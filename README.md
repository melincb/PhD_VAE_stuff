Data assimilation code and VAE for Chapter 3 of my doctoral thesis Preparing the Initial Conditions for Numerical Weather Prediction with Machine Learning (University of Ljubljana, 2026).

VAE weights are available at https://doi.org/10.5281/zenodo.21393305.
